AI-Powered GitHub Prospecting Agent

A proof-of-concept agentic AI tool that automatically identifies companies using an open-source library who've reported an issue on GitHub, researches them on the web, scores them as sales prospects, and recommends a next action - all without manual input.

n8n Claude (Anthropic) GitHub API Tavily Search

How it works

Agent orchestration flow

The n8n workflow - a Claude-powered agent orchestrating three tools on its own.

1

Search GitHub issues

The agent searches the product's public GitHub repository for the most recent bug reports and issues, filed by real developers actively using it - high-intent signals for prospecting.

2

Look up the reporter

For each issue author, the agent fetches their GitHub profile via an HTTP request to identify which company they work for.

3

Research with Tavily

Once a company is identified, the agent searches the web to understand what it does, its approximate size, and whether it builds data-heavy or dashboard products - the profile most likely to need the paid features.

What it outputs

Per run, per prospect

For each run, the agent produces a scored prospect card:

Company name Prospect score - High / Medium / Low Reasoning for the score Recommended action
